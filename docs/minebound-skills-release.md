# 礦脈紀行：職業招式第一階段

補齊 41 個 once 主動技能。技能取得仍依原職業等級。

- 治療、閃避、陷阱、凝視、基礎冰封：消耗 1 點累積答對，可在答題時直接使用。
- 一般攻擊技能：先選擇，再答對發動，取代該次普通攻擊。
- 群攻：需 2 點蓄力；Lv.20 攻擊：需 3 點蓄力，再答對發動。蓄力上限 6。
- 答錯或逾時取消選擇、清除連答紀錄，保留蓄力與本場施放次數。這版連答只顯示紀錄，不作使用門檻。
- 再點已選技能取消；未學會、已使用、非答題期間不可施放。
- 冰封依敵人個別扣回合；灼傷持續三回合；凝視三回合；免疫涵蓋當回合全體敵人。王者技能在下一次受到攻擊後反擊。
- 多段傷害逐擊套用既有抗性與傷害上限。百分比真傷對王級限制為最大生命25%，以避免瞬殺；圖鑑會註明。
- 八種特效方向：劍刃、冰晶、火焰、光印、音符、骰子、箭軌、暗影；陷阱和守護有專屬造型，多段招式有交錯斬影。尊重減少動態與音效開關。
- 主畫面的「招式」可看各職業定位、條件與預覽，無需修改角色或解鎖所有職業。

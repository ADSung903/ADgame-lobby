# 礦脈紀行：深度改版（2026-10-05）

## 交易與背包

- 販賣按物品造型與狀態合併成堆疊，提供數量減少／增加／全部、四類篩選、售價與名稱排序。
- 保留物品 ID 作為最終交易依據，核對後重新檢查商人距離與收藏鎖；連點不會重複付錢。
- 背包容量改成堆疊格數，件數另列。同樣的藥水可放入滿格背包，新的堆疊或裝備需要空格。
- 收藏、待鑑定、強化、前代遺物與不同品質不會混成同一堆疊。滿格時收藏拆分堆疊會提示先騰出空格。
- 移除大量空白占位格，分類與出售操作最小觸控目標維持約 44px。

## 知識與冒險

- 六組知識題庫共 144 題，冰原提供 24 種動態數列；保留原數學出題器。
- 知識題避開近期十二題；錯題至少隔十二道知識題後，於對應題庫優先複習。
- 數學難度獨立設定入門／標準／挑戰，預設入門。角色升級不會強迫提高。
- 一般／從容節奏（至少二十秒基礎時間）可選；戰鬥狀態減時仍生效。
- 首次走向未學習地區先展示 NPC 指南，可不限時練習後再繼續原本移動；關閉指南取消這次移動。
- 練習不改變 HP、消耗品、戰鬥勝利或任務答題次數。
- 戰後複習收錄最近三十道附解析的題目，減少戰鬥中的長段文字。
- 純數學模式也套用於地區事件。

## 九個當地事件

森林修復礦燈、沙漠解讀水源、冰原校準燈塔、深海救援信使、熔岩重啟熔爐、天空編織雲橋、暗影找回名字、機械修復通行訊號、核心留下傳承。

每個事件由 NPC 敘事與兩步不限時選擇組成，可暫停後繼續；不消耗材料。完成事件會在實際村落格子上留下不同顏色的礦紋，並成為新領取書頁的條件。舊存檔已收藏的書頁繼續保留，不要求重做。未造訪章節鎖定，避免提前揭露後續故事。

## 美術與聲音

九位 NPC 有地區景框、礦紋配件及服裝細節。六類武器有各自動畫節奏；火焰、流水、雪晶、雷電、岩片、暗環、光芒使用不同粒子圖形。暴擊放大仍受節點上限控制，減少動態偏好會關閉攻擊動畫。瀏覽器合成武器音效尊重原有音效開關與音量，不新增音訊下載。

世界畫冊新增九地旅人與武器元素特效兩個章節。數值傷害、怪物與世代存檔版本保持相容。

## 驗證

`dungeon-regression.cjs`、`dungeon-art-smoke.cjs`、`dungeon-adventure-commerce.cjs`：戰鬥、存檔初始化、題庫唯一性、滿格堆疊、數量上限、單瓶販售、收藏防護、一次性獎勵、事件連點防護、純數學事件、練習防刷進度、二十秒節奏。

`dungeon-art-raster.cjs`：369 個 SVG 實際渲染，涵蓋九位 NPC 和武器元素造型。模擬 DOM 測試不等同真實手機觸控測試；九大陸長時間完整通關仍需實機遊玩。

## 故事與 NPC

礦脈是一座失落的記憶庫。旅人帶著發光礦石走過九片土地，每完成一份委託，就收藏一頁記憶。死亡後，日誌與已收藏的書頁傳給下一代。

每份委託需要接取、在該地域答對三題並擊敗對應首領。完成後在紀行中回報，獲得書頁與金幣；獎勵只能領一次。日誌可隨時於非戰鬥期間翻閱，也可從村莊與當地 NPC 交談。既有探索路線和首領解鎖條件維持。

## 答題

新手森林維持原本數學題。其他地域約 65% 出當地題型、35% 數學；日誌可切換「只玩數學」。題庫目前包含 48 題有解析的英文／自然／邏輯題、動態數列及原有數學題。四個選項由同一題資料組成並隨機排序，不使用模型即時出題。

文字題使用至少 12 秒的基礎時間，再套用既有緩速、石化等戰鬥效果。答題傷害速度加成使用該題實際時間；答錯或逾時顯示正解與簡短解析。選項按鈕可顯示中文及短英文單詞。

## 武器特效

| 武器 | 命中特效 |
| --- | --- |
| 劍 | 弧形斬光、刃線與碎光 |
| 斧 | 下劈扇形斬光、地裂衝擊 |
| 弓 | 從主角飛向目標的三道箭光 |
| 法杖 | 旋轉符文圓、六芒圖形與晶核爆光 |
| 匕首 | 先後交叉的雙刃切痕 |
| 槍 | 從主角刺向目標的槍芒與穿透環 |

特效配合武器元素色與紋章；暴擊擴大並增加光環。只在玩家造成傷害時觸發，不把治療、毒傷或閃避誤顯示成武器攻擊。節點數設上限並定時移除，減少動畫設定關閉這些動態特效。傷害與數值不因動畫改變。

## 交易

商人提供獨立出售清單，按物品 ID 勾選、即時總價、核對清單及最後確認。每個勾選只賣一件，出售一瓶藥水不會清空同類堆疊。快捷選取只選普通／精良、未強化、已鑑定、非前代遺物且未收藏的背包裝備。物品詳情可切換收藏鎖，已裝備物品必須先卸下才可出售。確認時重新核對收藏狀態與商人距離，重複提交不能重複領金幣。商店售價優先作為消耗品回收價基準，購買按鈕區分金幣不足與背包已滿。

# 礦脈紀行：能力重配、平衡與聚落

## 能力與進度

首次進入改版發一張免費重配券，置於屬性頁，不占背包；使用前顯示退還點數，確認才扣券。戰鬥中禁止。新版記錄每項手動配點。

舊存檔原程式只有加點會改動五項基礎能力，升級只加生命和自由點；據此以初始能力差額與「升級已獲得點數－未分配點」交叉核對，完全吻合才恢復舊配點帳。無法吻合時保留全部能力，只退還新版可確認的手動點數，屬性頁明示。生命保留歷次升級累積值，力量直接加點的+1生命在退還時扣回，避免反覆加點刷生命。券狀態跨世代保留，不會再次領取。

力量劍3.4、斧4.2；智力法杖4.4；弓敏捷2.4+力量0.6；匕首敏捷1.8+幸運0.6；槍力量2.6+防禦1.0。另加等級攻擊，再套原職業/套裝/強化。敏捷閃避改為35%×敏捷/(敏捷+100)，加技能後上限50%；防禦不再增加閃避，敵人傷害也只在同一處計算防禦減傷。幸運暴擊35%×幸運/(幸運+60)，武器主屬性提供少量遞減補充，保留職業加成与上限。

加點預览和換裝比較直接呼叫實際戰鬥公式，移除先前裝備卡另一套錯誤攻擊估算。比較涵蓋攻擊、暴擊、閃避和答題時間。

角色升級需求80×等級^1.15，怪物經驗基礎+6×怪物等級^1.15。降低怪物生命/攻擊/防禦成長指數。職業每級需求4+floor(職業等級×0.75)，1到20需211场，較原1900場縮短；礦工50級仍可取得。遷移保留角色和職業等級、各自當前級進度比例。轉職經驗換算也使用同一曲線。

一般技能取消當前生命百分比封頂，讓不同倍率有實際差距；多段每擊85%攻擊，逐擊算防禦抗性；百分比真傷仍保留王級最大生命25%保護。本次不新增背刺標記/樂章組合機制，效果用途深化仍可討論。

## 聚落與鑑定

八座聚落從5×5擴為13×13安全區，石板道路、中央傳送石、噴泉、城界和八棟民居。六个獨立服務場所：月燈旅舍、旅人市場、星紋鑑定所、遠征公會、紀行會館、幸運會館。踩到各自門口使用，目錄只提供方向，避免一個入口包辦全部。市場附近才開放出售。住宿先確認500金，副本沿用原區域首領/遠征，賭場只使用遊戲金幣與原有玩法。

鑑定所可多選、全選，每件費用60金+需求等級×3金。不消耗卷軸，先預覽總費用再確認。提交時重新檢查位置、物品、費用、資金；重複提交不重複扣款，鑑定後顯示真實名稱與能力。

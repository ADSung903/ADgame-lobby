# 礦洞冒險：美術與戰鬥修正

![Original vector monster artwork](dungeon-art-preview.png)

此版使用墨綠、黃銅、羊皮紙色的冒險手冊視覺。怪物採用共用插畫系統，覆蓋既有怪物與副本 Boss，地圖、戰鬥、圖鑑使用相同造型。此預覽是素材圖，不是遊戲畫面截圖。

- 11 個怪物造型家族，搭配元素色與菁英皇冠；屬於第一版統一美術，尚非每隻怪物的獨立專屬插畫。
- 九大陸戰鬥場景：森林、沙漠、冰原、熔岩、海底、天空、暗影、機械、隱藏區域。
- 新地面紋理、樹木、山峰；旅館、寶箱、傳送石沿用原有 Canvas 素材。
- 介面、背包、物品卡、戰鬥題目與答題按鈕统一配色。
- 修正答題速度計時、後續回合推進、回合冷卻與狀態倒數、單體技能多人勝利判定。
- 修正元素判定使用實際被攻擊目標，擊殺數按敵人數計算，移除重複初始化。
- 舊存檔保留並補預設欄位；沒有調高 SAVE_VERSION。

驗證：`node tests/dungeon-regression.cjs`，以及 `git diff --check`。

限制：環境缺少可用瀏覽器，瀏覽器下載失敗；尚未完成實機手機與桌面排版、觸控、音效和完整冒險流程驗證。建議測試 320/390/430px 寬度、短螢幕、三隻怪物、長技能列和裝備圖鑑再合併。
